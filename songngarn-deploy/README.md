# songngarn (ส่งงาน) 📚✨
### ระบบรับ-ส่งงานและประเมินผลออนไลน์ โรงเรียนพัฒนานิคม
**กลุ่มสาระการเรียนรู้วิทยาศาสตร์และเทคโนโลยี**  
**ผู้ดูแลระบบ / ครูผู้สอน:** นายปารเมศ มหิเมือง (รหัส 12004)

---

## 🌟 คุณสมบัติเด่นของระบบ

1. **ระบบเข้าสู่ระบบแยกครูและนักเรียน**
   - **สำหรับครู:** รหัสประจำตัว `12004` (นายปารเมศ มหิเมือง) เป็นแอดมินใหญ่ของระบบ เข้าสู่ระบบเพื่อจัดการชั้นเรียน สั่งงาน และตัดเกรด
   - **สำหรับนักเรียน:** ใช้ **เลขประจำตัวนักเรียน 5 หลัก** (เช่น `54001`) เป็นรหัสผ่านเข้าสู่ระบบโดยตรง ไม่ต้องจำรหัสผ่านซับซ้อน

2. **ระบบจัดการชั้นเรียน (Classroom Management)**
   - สร้างชั้นเรียนคล้าย Google Classroom
   - กำหนดข้อมูลวิชา: ชื่อวิชา, รหัสวิชา (เช่น ว31101), ชั้น (เช่น ม.4/1), สถานที่เรียน และเวลาเรียน
   - **ตั้งค่าสัดส่วนคะแนนตามแผนวัดประเมินผลของโรงเรียน (4 ส่วน):**
     1. **ก่อนกลางภาค:** สามารถเพิ่ม/ลดจำนวนช่องคะแนนเก็บได้อิสระ พร้อมระบุคะแนนเต็มแต่ละช่อง
     2. **กลางภาค:** 1 ช่องคะแนนสอบกลางภาค
     3. **หลังกลางภาค:** สามารถเพิ่ม/ลดจำนวนช่องคะแนนเก็บได้อิสระ พร้อมระบุคะแนนเต็มแต่ละช่อง
     4. **ปลายภาค:** 1 ช่องคะแนนสอบปลายภาค
     - ผลรวม 100 คะแนน และสามารถปรับเปลี่ยนสัดส่วนภายหลังได้ตลอดเวลา

3. **นำเข้ารายชื่อนักเรียนจาก Excel / CSV**
   - อัปโหลดไฟล์ `.xlsx` หรือ `.csv` ที่มีหัวคอลัมน์: **ชั้น, เลขที่, เลขประจำตัว, ชื่อสกุล**
   - มีปุ่มดาวน์โหลดไฟล์แม่แบบตัวอย่าง CSV ให้ทันที

4. **การสั่งงานและระบบคำนวณสัดส่วนคะแนนอัตโนมัติ (Proportional Score Engine)**
   - สั่งงานโดยระบุ ชื่องาน, คะแนนเต็ม, กำหนดส่ง, รายละเอียด, แนบไฟล์ใบงานหรือลิงก์
   - เลือกว่าเป็น **งานเดี่ยว** หรือ **งานกลุ่ม**
   - **ผูกงานเข้ากับช่องคะแนนตามแผนวัดผล:**  
     เช่น งานชิ้นนี้สังกัด *ก่อนกลางภาค ช่องที่ 1 (ตั้งใจเก็บ 10 คะแนน)* แม้จะมีงาน 2 ชิ้น ชิ้นละ 20 คะแนน (คะแนนเต็มดิบรวม 40) ระบบจะทอนและคำนวณสัดส่วนให้อัตโนมัติให้กลายเป็นเต็ม 10 คะแนนเพื่อนำไปกรอกระบบวัดผลของโรงเรียนต่อไป
   - **ปุ่มเปิด-ปิดรับงาน:** ครูสามารถกดคลิกเดียวเพื่อปิดรับงานเมื่อหมดเวลา หรือเปิดรับงานใหม่ได้ตลอดเวลา

5. **ระบบส่งงานสำหรับนักเรียน (Student Portal)**
   - เข้าสู่ระบบด้วยรหัส 5 หลัก จะแสดงห้องเรียนทั้งหมดที่นักเรียนมีรายชื่อ
   - แสดงสถานะงานอย่างชัดเจนตามเงื่อนไข:
     - 🟢 **ส่งแล้วตรวจแล้ว**: ขึ้นคะแนนที่ได้รับ และข้อคิดเห็น/คำแนะนำจากครู
     - 🟡 **ส่งแล้วรอตรวจ**: แสดงไฟล์ที่ส่งไปแล้ว สามารถแก้ไขส่งใหม่ได้
     - ⚪ **ยังไม่ส่ง**: ยังอยู่ในช่วงเวลาส่ง
     - 🟠 **พ้นกำหนดส่งได้อยู่**: เลยกำหนดส่งแล้ว แต่ครูยังเปิดรับอยู่ (จะขึ้นสถานะ "ส่งล่าช้า")
     - 🔴 **พ้นกำหนดปิดรับงาน**: ครูปิดรับงานแล้ว ไม่สามารถส่งได้
   - แนบไฟล์ได้หลากหลาย: รูปภาพ (มีภาพตัวอย่าง Preview), ไฟล์ PDF, และลิงก์ (Google Drive, Canva, Docs, ฯลฯ)
   - **งานกลุ่ม:** นักเรียนกรอกรหัสประจำตัว 5 หลักของเพื่อนในกลุ่มทุกคน โดยระบบจะดึงชื่อ-สกุลของเพื่อนขึ้นมาแสดงอัตโนมัติ เพื่อให้ครูตรวจให้คะแนนทุกคนได้พร้อมกัน

6. **ระบบตรวจงานและให้คะแนน (Grading Interface)**
   - ดูรายการส่งงาน แยกตามสถานะ (รอตรวจ / ตรวจแล้ว / ส่งล่าช้า)
   - ดูไฟล์ภาพ PDF และลิงก์ผลงานของนักเรียนได้โดยตรง
   - **งานกลุ่ม:** ครูสามารถกรอกคะแนนครั้งเดียวแล้วกดปุ่ม **"ให้คะแนนทุกคนเท่ากัน"** หรือปรับแก้คะแนนแยกรายบุคคลได้ตามต้องการ
   - บันทึกข้อเสนอแนะรายบุคคล หรือข้อคิดเห็นรวมถึงทั้งกลุ่ม

7. **ตารางคะแนนรวมและส่งออก Excel (Gradebook & Export)**
   - ตารางคะแนนรวมทั้งห้องเรียน แสดงคะแนนดิบรายชิ้นงาน, คะแนนทอนสัดส่วนแต่ละช่อง, รวมก่อนกลาง, กลางภาค, รวมหลังกลาง, ปลายภาค, คะแนนรวม 100 และเกรด (0 - 4)
   - **ปุ่มดาวน์โหลด Excel (.xlsx):** ส่งออกไฟล์ Excel สวยงามพร้อมนำไปกรอกในระบบของโรงเรียน

## 🚀 วิธีการเปิดใช้งานระบบ (Getting Started)

### 1. รันระบบในโหมดพัฒนา (Development Mode)
```bash
npm run dev
```
เปิดบราวเซอร์ไปที่: `http://localhost:3000`

### 2. รันระบบในโหมด Production
```bash
npm run build
npm start
```

## 📁 โครงสร้างโปรเจกต์ (Project Structure)
```
songngarn/
├── data/
│   └── db.json               # ฐานข้อมูล JSON ที่บันทึกถาวร (Classrooms, Students, Assignments, Submissions)
├── public/

├── src/
│   ├── app/
│   │   ├── api/              # REST APIs (Auth, Classrooms, Students, Assignments, Submissions, Grades, Upload)
│   │   ├── teacher/          # หน้าสำหรับคุณครู (Classroom list, Detail, Grading)
│   │   ├── student/          # หน้าสำหรับนักเรียน (Classroom list, Submission modal, Grade report)
│   │   ├── globals.css       # Tailwind CSS & Thai typography
│   │   ├── layout.tsx
│   │   └── page.tsx          # หน้าแรก เลือกล็อกอินครู หรือ นักเรียน
│   └── lib/
│       ├── types.ts          # โครงสร้าง Type ต่างๆ
│       ├── db.ts             # โมดูลจัดการฐานข้อมูล JSON
│       ├── grade-calculator.ts # กลไกคำนวณและทอนสัดส่วนคะแนนตามแผนวัดผล
│       └── excel-helper.ts   # โมดูลวิเคราะห์ไฟล์รายชื่อ Excel/CSV และสร้างรายงาน Excel
└── package.json
```
